# 青松团队安全发布链路对接接口文档

版本：v1.2

日期：2026-07-02

适用范围：青松团队信发平台、安全发布客户端 `info-publish-client`

## 1. 对接目标

安全发布客户端向青松团队提供安全发布链路接口，覆盖节目单获取、发布前预检验、内容发布和情报板控制指令。

当前生产对接包含三条主链路：

1. 青松提供节目单回调接口，客户端按情报板 IP 获取待发布内容。
2. 青松调用客户端 `POST /api/client/publish/precheck` 做发布前预检验并获取发布许可。
3. 青松调用客户端 `POST /api/client/publish/execute` 发起内容发布。
4. 青松调用客户端 `POST /api/client/commands/execute` 执行控制指令。

控制指令接口采用同步等待最终结果模式：客户端完成本地安全校验、参数校验、加密网关投递、解密网关执行结果等待，并在本次 HTTP 响应中返回最终执行结果。

## 2. 对接边界

| 模块 | 责任 |
|---|---|
| 青松团队信发平台 | 提供节目单回调接口；调用客户端预检验、内容发布、控制指令接口 |
| 安全发布客户端 | 参数校验、安全状态校验、获取节目单、下载并校验文件、签发发布许可、调用加密网关 |
| 加密网关 | 内容发布/控制任务加密、投递到解密网关、聚合解密网关状态 |
| 解密网关 | 解析内容发布包或控制任务，按目标设备 IP 匹配设备，调用厂商协议执行 |
| 情报板设备 | 接收并执行厂商协议指令 |

## 3. 接口基础信息

| 项目 | 值 |
|---|---|
| 协议 | HTTP |
| 客户端地址 | `http://127.0.0.1:7081` |
| 内容类型 | `application/json;charset=UTF-8` |
| 字符编码 | UTF-8 |
| 认证方式 | 本机调用，当前不额外增加 HTTP 鉴权 |

## 4. 主流程

### 4.1 发布前预检验流程

1. 青松调用 `POST /api/client/publish/precheck`，传入 `requestId`、`sigmaBaseUrl`、`target.ip`。
2. 客户端通过 `GET {sigmaBaseUrl}/api/v1/callback/program-by-ip?ip={target.ip}` 获取青松节目单。
3. 客户端校验 UKey、客户端认证、信发平台进程绑定、网关链路、节目单结构。
4. 校验通过后客户端生成 `playlistDigest` 和 `publishPermit`，并在响应中返回 `target`、`items`。

### 4.2 内容发布流程

1. 青松调用 `POST /api/client/publish/execute`，传入 `requestId`、`sigmaBaseUrl`、`target.ip`。
2. 客户端再次调用青松节目单回调接口获取节目单。
3. 客户端下载 `items[].fileUrl` 指向的文件，并用 `items[].fileHash` 做 SHA-256 校验。
4. 客户端内部执行 precheck 并签发 `publishPermit`。
5. 客户端调用加密网关 `/api/secure-delivery/tasks` 投递内容发布任务。
6. 客户端返回稳定分层响应，包含 `playlist`、`target`、`checks`、`delivery`。

### 4.3 控制指令流程

1. 青松调用 `POST /api/client/commands/execute` 提交控制指令。
2. 客户端完成本地安全校验、参数校验、加密网关投递。
3. 解密网关按目标设备 IP 匹配设备并执行厂商协议。
4. 客户端同步等待最终结果并返回结构化响应。

## 5. 青松节目单回调接口

该接口由青松团队信发平台提供，客户端在 precheck 和 publish execute 中都会调用。

```http
GET {sigmaBaseUrl}/api/v1/callback/program-by-ip?ip={ip}
```

### 5.1 请求参数

| 字段 | 位置 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `ip` | query | string | 是 | 情报板 IP，例如 `192.168.113.239` |

客户端会额外携带以下请求头，青松可按需记录：

| Header | 说明 |
|---|---|
| `X-SP-Client-Id` | 固定值 `secure-publish-client` |
| `X-SP-Request-Id` | 客户端生成的请求 ID |
| `X-SP-Timestamp` | 客户端请求时间 |

### 5.2 响应字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `code` | integer | 是 | `0` 表示成功 |
| `message` | string | 否 | 错误或提示信息 |
| `data.success` | boolean | 是 | 节目单获取是否成功 |
| `data.playlistId` | string | 是 | 青松节目单 ID |
| `data.target` | object | 是 | 目标情报板 |
| `data.target.deviceId` | string | 建议 | 青松侧设备 ID。可为 IP 去点后的值或设备侧标识 |
| `data.target.ip` | string | 是 | 目标情报板 IP，必须与请求 `ip` 一致 |
| `data.target.port` | integer | 是 | 目标情报板端口，通常为 `9520` |
| `data.target.vendorHint` | string | 否 | 厂商提示，如 `JETFILEII` |
| `data.items` | array | 是 | 待发布文件列表，不能为空 |
| `data.items[].orderNo` | integer | 是 | 播放顺序，从 `1` 开始 |
| `data.items[].fileName` | string | 是 | 文件名 |
| `data.items[].fileType` | string | 是 | 文件类型，如 `image` |
| `data.items[].fileUrl` | string | 是 | 文件下载地址，客户端必须可访问 |
| `data.items[].durationSeconds` | integer | 是 | 播放时长，必须大于 `0` |
| `data.items[].fileHash` | string | 内容发布必填 | 文件 SHA-256 摘要，内容发布会强校验 |

### 5.3 响应示例

```json
{
  "code": 0,
  "message": "",
  "data": {
    "success": true,
    "playlistId": "86",
    "target": {
      "deviceId": "192168113239",
      "ip": "192.168.113.239",
      "port": 9520,
      "vendorHint": "JETFILEII"
    },
    "items": [
      {
        "orderNo": 1,
        "fileName": "88.bmp",
        "fileType": "image",
        "fileUrl": "http://192.168.113.123:3225/cache/88.bmp",
        "durationSeconds": 5,
        "fileHash": "19317766c517d135a9a0db861fe381d594b0f5e6d172550be09f46d9b98259f3"
      }
    ]
  }
}
```

## 6. 发布前预检验接口

```http
POST /api/client/publish/precheck
Content-Type: application/json;charset=UTF-8
```

兼容入口：`POST /api/publish/precheck`。新对接建议统一使用 `/api/client/publish/precheck`。

### 6.1 请求字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `requestId` | string | 是 | 请求唯一 ID，也是幂等键 |
| `sigmaBaseUrl` | string | 是 | 青松平台接口根地址，例如 `http://192.168.113.123:3225` |
| `operatorId` | string | 否 | 操作人 ID，用于审计 |
| `playlistId` | string | 否 | 可不传。为空时客户端按 `target.ip` 调青松节目单接口 |
| `target` | object | 是 | 目标情报板 |
| `target.ip` | string | 是 | 目标情报板 IP |
| `target.port` | integer | 否 | 目标端口，通常为 `9520` |
| `target.deviceId` | string | 否 | 设备 ID |
| `target.vendorHint` | string | 否 | 厂商提示 |
| `items` | array | 否 | 可不传。若 `playlistId`、`target`、`items` 全部传入，则客户端直接使用请求节目单 |
| `timeoutMs` | integer | 否 | 整体超时时间，默认 `300000` 毫秒 |

### 6.2 请求示例

```json
{
  "requestId": "REQ-CONTENT-TEST-0001",
  "sigmaBaseUrl": "http://192.168.113.123:3225",
  "operatorId": "operator-001",

    "vendorHint": "QINGSONG"

}
```

### 6.3 响应字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `success` | boolean | 接口是否执行成功 |
| `publishAllowed` | boolean | 是否允许继续发布 |
| `allowed` | boolean | 兼容字段，与 `publishAllowed` 一致 |
| `result` | string | `PASS` 或 `FAILED` |
| `playlistId` | string | 青松节目单 ID |
| `checks` | object | 基础检查结果 |
| `checks.ukeyAuthenticated` | boolean | UKey 是否认证 |
| `checks.clientAuthenticated` | boolean | 客户端是否认证 |
| `checks.sigmaProcessBound` | boolean | 信发平台进程是否绑定 |
| `checks.gatewayReady` | boolean | 网关链路是否可用 |
| `checks.allPassed` | boolean | 四项基础检查是否全部通过 |
| `checkResult` | object | 文件检查结果，目前预检验阶段通常为空结果 |
| `message` | string | 结果说明 |
| `requestId` | string | 请求 ID |
| `precheckId` | string | 预检验 ID，当前复用 `requestId` |
| `publishPermit` | string | 发布许可 JWT，`PASS` 时返回 |
| `playlistDigest` | string | 播放列表摘要，`PASS` 时返回 |
| `permitMessage` | string | 发布许可签发说明 |
| `infoBoardIp` | string | 情报板 IP |
| `infoBoardPort` | integer | 情报板端口 |
| `target` | object | 青松节目单目标设备 |
| `items` | array | 青松节目单文件列表 |

## 7. 内容发布接口

```http
POST /api/client/publish/execute
Content-Type: application/json;charset=UTF-8
```

该接口是生产内容发布入口。青松只需要传目标设备和 `sigmaBaseUrl`，客户端负责获取节目单、下载文件、校验 Hash、执行 precheck、投递加密网关。

### 7.1 请求字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `requestId` | string | 是 | 请求唯一 ID，也是幂等键 |
| `sigmaBaseUrl` | string | 是 | 青松平台接口根地址 |
| `operatorId` | string | 否 | 操作人 ID |
| `target` | object | 是 | 目标情报板 |
| `target.ip` | string | 是 | 目标情报板 IP |
| `target.port` | integer | 否 | 目标端口，通常为 `9520` |
| `target.deviceId` | string | 否 | 设备 ID |
| `target.vendorHint` | string | 否 | 厂商提示 |
| `options` | object | 否 | 发布选项 |
| `options.clearBeforePublish` | boolean | 否 | 发布前是否清空旧内容，默认 `true` |
| `options.checkExistence` | boolean | 否 | 是否检查文件存在性，默认 `true` |
| `options.waitForDelivery` | boolean | 否 | 是否要求加密网关等待投递结果，由网关实现决定 |
| `timeoutMs` | integer | 否 | 整体超时时间，默认 `300000` 毫秒 |

### 7.2 请求示例

```json
{
  "requestId": "REQ-PUBLISH-20260702-0001",
  "sigmaBaseUrl": "http://192.168.113.123:3225",
  "operatorId": "operator-001",
  "target": {
    "ip": "192.168.113.239",
    "port": 9520,
    "vendorHint": "QINGSONG"
  },
  "options": {
    "clearBeforePublish": true,
    "checkExistence": true
  }
}
```

### 7.3 响应字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `success` | boolean | 内容发布接口是否处理成功 |
| `code` | string | 状态码。成功为 `ACCEPTED` |
| `message` | string | 结果说明 |
| `requestId` | string | 请求 ID |
| `playlist` | object | 节目单摘要 |
| `playlist.playlistId` | string | 青松节目单 ID |
| `playlist.digest` | string | 客户端计算的播放列表摘要 |
| `playlist.itemCount` | integer | 文件数量 |
| `playlist.items` | array | 文件列表，来自青松节目单接口 |
| `target` | object | 目标情报板，来自青松节目单接口 |
| `checks` | object | 预检验摘要 |
| `checks.passed` | boolean | 预检验和文件校验是否都通过 |
| `checks.ukeyAuthenticated` | boolean | UKey 是否认证 |
| `checks.clientAuthenticated` | boolean | 客户端是否认证 |
| `checks.sigmaProcessBound` | boolean | 信发平台进程是否绑定 |
| `checks.gatewayReady` | boolean | 网关链路是否可用 |
| `checks.filesVerified` | boolean | 文件下载和 SHA-256 校验是否通过 |
| `delivery` | object | 加密网关投递摘要 |
| `delivery.deliveryTaskId` | string | 加密网关投递任务 ID |
| `delivery.status` | string | 加密网关返回状态 |
| `delivery.createdAt` | integer | 加密网关任务创建时间戳 |

## 8. 执行控制指令

```http
POST /api/client/commands/execute
Content-Type: application/json;charset=UTF-8
```

### 8.1 公共请求字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `requestId` | string | 是 | 请求唯一 ID，也是幂等键。相同 `requestId` 会复用已有任务结果 |
| `operatorId` | string | 是 | 操作人 ID，用于审计 |
| `command` | string | 是 | 控制指令，必须使用本文档列出的英文大写值 |
| `target` | object | 是 | 目标设备信息 |
| `target.ip` | string | 是 | 目标设备 IP。当前生产匹配优先使用 IP |
| `target.port` | integer | 是 | 目标设备端口，范围 `1-65535`，青松情报板通常为 `9520` |
| `target.deviceId` | string | 否 | 设备 ID。可传青松返回的设备标识，但当前不作为唯一匹配条件 |
| `target.vendorHint` | string | 否 | 厂商提示，如 `QINGSONG`、`JET_FILE_II`、`JETFILEII` |
| `params` | object | 视指令而定 | 指令参数。无参数指令可省略或传 `{}` |

### 8.2 支持的 command

| command | 中文含义 | 是否生产开放 | 说明 |
|---|---|---|---|
| `QUERY_STATUS` | 查询设备状态 | 是 | 查询设备基础状态和结构化设备信息 |
| `BRIGHTNESS` | 调节亮度 | 是 | 设置亮度百分比 |
| `BLACKOUT` | 黑屏/恢复显示 | 是 | `true` 黑屏，`false` 恢复显示 |
| `REBOOT` | 重启设备 | 是 | 无参数 |
| `TIME_SYNC` | 单次校时 | 是 | 可传时间；不传时客户端补当前时间 |
| `NTP_SET` | 设置 NTP 服务 | 是，运维能力 | 适合生产长期校时 |
| `DEVICE_IP_SET` | 修改设备网络配置 | 预留，高风险 | 需要 `confirm=true`，默认只给运维/安装人员 |
| `SCREEN_ATTRIBUTE_SET` | 设置屏体属性 | 预留，高风险 | 需要 `confirm=true`，默认只给安装调试人员 |

说明：`POWER` 当前不对外开放。恢复显示请使用 `BLACKOUT` 且 `enabled=false`，重启请使用 `REBOOT`。

## 9. 控制指令参数明细

### 9.1 QUERY_STATUS

查询设备状态。无业务参数。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `params` | object | 否 | 可省略或传 `{}` |

请求示例：

```json
{
  "requestId": "REQ-CMD-QUERY-001",
  "operatorId": "operator-001",
  "command": "QUERY_STATUS",
  "target": {
    "ip": "192.168.113.239",
    "port": 9520,
    "vendorHint": "QINGSONG"
  }
}
```

### 9.2 BRIGHTNESS

调节设备亮度。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `params.brightness` | integer | 是 | 亮度值，范围 `0-100` |

请求示例：

```json
{
  "requestId": "REQ-CMD-BRIGHTNESS-001",
  "operatorId": "operator-001",
  "command": "BRIGHTNESS",
  "target": {
    "ip": "192.168.113.239",
    "port": 9520,
    "vendorHint": "QINGSONG"
  },
  "params": {
    "brightness": 80
  }
}
```

### 9.3 BLACKOUT

黑屏或恢复显示。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `params.enabled` | boolean | 是 | `true` 表示开启黑屏，`false` 表示关闭黑屏并恢复显示 |

请求示例，开启黑屏：

```json
{
  "requestId": "REQ-CMD-BLACKOUT-001",
  "operatorId": "operator-001",
  "command": "BLACKOUT",
  "target": {
    "ip": "192.168.113.239",
    "port": 9520,
    "vendorHint": "QINGSONG"
  },
  "params": {
    "enabled": true
  }
}
```

请求示例，恢复显示：

```json
{
  "requestId": "REQ-CMD-BLACKOUT-002",
  "operatorId": "operator-001",
```

### 14.2 验收标准

1. 青松 `GET /api/v1/callback/program-by-ip?ip=...` 能返回 `code=0`、`data.success=true`、非空 `playlistId` 和非空 `items`。
2. `items[].fileUrl` 必须能被客户端访问；内容发布时 `items[].fileHash` 必须与文件 SHA-256 一致。
3. `POST /api/client/publish/precheck` 成功时返回 `publishAllowed=true`、`result=PASS`、非空 `publishPermit`、非空 `playlistDigest`、`target`、`items`。
4. `POST /api/client/publish/execute` 成功时返回 `success=true`、`code=ACCEPTED`、非空 `playlist.playlistId`、非空 `delivery.deliveryTaskId`。
5. `POST /api/client/commands/execute` 在同一次响应中返回最终状态。
6. 控制指令执行成功时返回 `success=true`、`status=SUCCESS`、`finalResult=true`。
7. 控制指令执行失败、链路失败、设备未匹配或等待超时时返回 `success=false`。
8. `QUERY_STATUS` 成功时返回结构化 `deviceInfo`。
9. 生产响应不包含 `remoteStatus`、`rawText`、`rawEncoding`、设备磁盘明细和网关内部任务包。
10. `DEVICE_IP_SET` 和 `SCREEN_ATTRIBUTE_SET` 未传 `confirm=true` 时必须被拒绝。
11. `POWER` 指令必须被拒绝，不进入加密网关投递链路。
